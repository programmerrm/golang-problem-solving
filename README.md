# Golang Problem Solving

A collection of Go (Golang) solutions for algorithmic problems, data structures, and coding challenges.

This repository is focused on improving problem-solving skills, algorithmic thinking, data structure knowledge, and Go programming fundamentals — from beginner concepts to advanced topics.

## Topics Covered

- **Arrays & Strings** — Manipulation, searching, sorting
- **Linked Lists** — Singly/doubly linked list operations
- **Stacks & Queues** — LIFO/FIFO implementations
- **Trees & Graphs** — Binary trees, BST, BFS, DFS
- **Sorting & Searching** — Quick sort, merge sort, binary search
- **Dynamic Programming** — Memoization, tabulation
- **Recursion & Backtracking** — Combinations, permutations
- **Hash Maps** — Frequency counting, two-sum patterns
- **Concurrency** — Goroutines, channels, sync patterns
- **Math & Bit Manipulation** — Prime numbers, bitwise operations

## Goals

- Strengthen algorithmic problem-solving skills
- Master data structures and algorithms
- Practice writing clean and efficient Go code
- Improve time and space complexity analysis
- Build a strong foundation for technical interviews and competitive programming
