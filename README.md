# Golang-Problem-Solving

A collection of Go solutions for algorithmic problems, data structures, and coding challenges. This repository demonstrates problem-solving skills using Go (Golang) — covering topics from basics to advanced.

## Topics Covered

- **Arrays & Strings** — Manipulation, searching, sorting
- **Linked Lists** — Singly/doubly linked list operations
- **Stacks & Queues** — LIFO/FIFO implementations
- **Trees & Graphs** — Binary trees, BST, BFS, DFS
- **Sorting & Searching** — Quick sort, merge sort, binary search
- **Dynamic Programming** — Memoization, tabulation
- **Recursion & Backtracking** — Combinations, permutations
- **Hash Maps** — Frequency counting, two-sum patterns
- **Concurrency** — Goroutines, channels, sync patterns
- **Math & Bit Manipulation** — Prime numbers, bitwise operations
